又叫SOSDP，可以用来处理一些子集相关的问题
先看熟悉的二维前缀和的写法
```cpp
for(int i = 1; i <= n; i++)
	for(int j = 1; j <= n; j++)
		sum[i][j] = sum[i - 1][j] + sum[i][j - 1] - sum[i - 1][j - 1];
```
这里用到了容斥原理，减去了重复计算的部分，如果拓展到高维，那么容斥的复杂度会很高
可以这样优化
```cpp
for(int i = 1; i <= n; i++)
	for(int j = 1; j <= n; j++)
		sum[i][j] += sum[i][j - 1];
for(int i = 1; i <= n; i++)
	for(int j = 1; j <= n; j++)
		sum[i][j] += sum[i - 1][j];
```
先转移第一维，再转移第二维
同样的，三维前缀和
```cpp
for(int i = 1; i <= n; i++)
    for(int j = 1; j <= n; j++)
        for(int k = 1; k <= n; k++) 
            a[i][j][k] += a[i - 1][j][k];
for(int i = 1; i <= n; i++)
    for(int j = 1; j <= n; j++)
        for(int k = 1; k <= n; k++)
            a[i][j][k] += a[i][j - 1][k];
for(int i = 1; i <= n; i++)
    for(int j = 1; j <= n; j++)
        for(int k = 1; k <= n; k++)
            a[i][j][k] += a[i][j][k - 1];

```
接下来，就可以自然地拓展到n维了，这里固定每一维的长度为2
```cpp
for(int i = 0; i < n; i++)
	for(int mask = 0; mask < (1 << n); mask++)
		if(mask & (1 << i))
			sum[mask] += sum[mask ^ (1 << i)];
```
代码第一行枚举进行转移的维度，第二行遍历高维空间，这里相当于把 `sum[2][2][2]...` 状压成了 `sum[1<<N]` ，第三行判断遍历到的位置的第 `i` 维是否为1，如果是，那么进行转移，复杂度 $O(n 2^n)$ 
那么高维前缀和有什么用呢
高维前缀和其实在求这样的问题
假设你有一个长度为 $2^n$ 的数组 $A$（下标从 $0$ 到 $2^n-1$），每一个下标可以看作一个有 $n$ 个元素的集合的二进制压缩表示。
现在你需要求出一个新的数组 $F$，使得：
$$F[mask] = \sum_{sub \subseteq mask} A[sub]$$
这里的求和运算可以换成其他满足结合律的运算
同时可以自定义结构体，自定义运算
```cpp
struct node {
	int a, b...
	friend operator + (node x, node y) {
		node ans;
		...
		return ans;
	}
} sum[1<<N];

int main() {
	for(int i = 0; i < n; i++)
		for(int mask = 0; mask < (1 << n); mask++)
			if(mask & (1 << i))
				sum[mask] = sum[mask] sum[mask ^ (1 << i)];
}
```
