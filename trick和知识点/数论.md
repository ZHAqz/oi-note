# 最大的无法用两个互质的数表示的数（P3951)
设 a，b 互质，根据裴蜀定理，$\exists x, y \in \mathbb{Z}, ax + by = 1$
所以任意的整数都可以用 a, b 表示，但是当这个数一定小的时候， x 或 y 会变为负数，求的就是这类数中最大的
$$
c = ax + by,x < 0或y < 0,a < b
$$
让 x = -1 ，y = a - 1
这时原式化为
$$
-a + b(a - 1) = ab - a - b
$$
这就是答案
# 枚举倍数和因数的复杂度
$$ \sum_{i = 1} ^ n d(i) = \sum_{i = 2} ^ n \frac{n}{i} = n log n $$
$d(i)$ 是 $i$ 的因子个数
也就是说
```cpp
for(int i = 1; i <= n; i++)
	for(int j = 1; j * i <= n; j++)
		//O(1)
```
这个代码的复杂度是 $O(n\log n)$ 的
可以用调和级数证明
特别的，对于单个数，枚举它的每个因数的复杂度是 $O(\sqrt{n})$ 的，因为因数是成对出现的

# 模意义下幂运算指数部分不能轻易取模
在模数是大质数的情况下
$$
a^b \equiv a^{b \bmod p} \pmod p
$$
不总是成立
事实上，由费马小定理，在 $a \bmod p \neq 0$ 时
$$
a^b \equiv a^{b \bmod (p-1)} \pmod p
$$
