# 最大的无法用两个互质的数表示的数（P3951)
设 a，b 互质，根据裴蜀定理，$\exists x, y \in \mathbb{Z}, ax + by = 1$
所以任意的整数都可以用 a, b 表示，但是当这个数一定小的时候， x 或 y 会变为负数，求的就是这类数中最大的
$$
c = ax + by,x < 0或y < 0,a < b
$$
让 x = -1 ，y = a - 1
这时原式化为
$$
-a + b(a - 1) = ab - a - b
$$
这就是答案
# 枚举倍数和因数的复杂度
$$ \sum_{i = 1} ^ n d(i) = \sum_{i = 2} ^ n \frac{n}{i} = n log n $$ $d(i)$ 是 $i$ 的因子个数
可以用调和级数证明
特别的，对于单个数，枚举它的每个因数的复杂度是 $O(\sqrt{n})$ 的，因为因数是成对出现的
# 互质因子的整除性质
如果两个整数 $A$ 和 $B$ 互质，那么对于任意整数 $X$
$$A \times B \mid X \iff A \mid X 且 B \mid X$$
