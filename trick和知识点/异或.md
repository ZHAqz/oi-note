# 最小异或对
给定一组数，从中选出两个数，求最小异或值
结论：**对于三个有序的整数 $a \le b \le c$，必然满足：
$$a \oplus c \ge \min(a \oplus b, b \oplus c)$$**
> [!info]- 证明
> 由于 $a \le c$，肯定存在某一位使得 $a$ 和 $c$ 不同。 设 **第 $k$ 位** 是 $a$ 和 $c$ 二进制表示中**从高到低数第一个不同的位**。 因为 $a < c$，所以在第 $k$ 位上
>- $a$ 的第 $k$ 位必然是 **0**
>- $c$ 的第 $k$ 位必然是 **1**。
>- 在 $k$ 位以上的所有高位（$k+1, k+2, \dots$），$a$ 和 $c$ 完全相同。
分析中间数 $b$
>- 在 $k$ 位以上的所有高位上，$a$ ，$b$ ，$c$ ，完全相同
>- b的第 $k$ 位不是0就是1
>如果是0，显然 $a \oplus b < a \oplus c$
>如果是1，继续向下一位比较，因为 $a < b < c$ ，所以存在一位 $i$ ，使得 $a_{i} = 0,b_{i} = 0, c_{i} = 1$这时，就可以断定 $a \oplus b <  a \oplus c$
>综上，证毕

所以就可以把序列排序一下，比较相邻的的两个数，复杂度 $O(n \log n)$
# 最大异或对
上一个题的最小变成了最大
用**01trie**
用序列中的数建01trie，枚举每一个数，贪心地在树上找到与它异或起来最大的数，取max
复杂度 $O(n \log v)$ v是数字数位数
