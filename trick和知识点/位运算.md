# lowbit
```cpp
x & -x
```
可以得到 `x` 的最后一个1
# lowbit对应反操作
```cpp
x & (x -1)
```
可以抹去 `x` 的最后一个1
# 枚举子集
给定一个集合A,我们要枚举A的每个子集，同时枚举子集中的每个元素
```cpp
for(int mask = 0; mask < (1 << n); mask++)
	for(int i = mask; i > 0; i = (i - 1) & mask) {
		//要进行的操作
	}
```
枚举子集的时间复杂度是 $O(3^n)$，原因是二项式定理
 $$
 \sum_{i = 0} ^ n 2 ^ i \binom{n}{i} = (2 + 1) ^ n = 3 ^ n 
 $$
