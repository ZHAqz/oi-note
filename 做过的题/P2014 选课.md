#dp 
树形背包
定义`f[u][i][j]`为以u为根的子树里，在前i个节点里选，总共选j个的方案数
`f[u][i][j] = max(f[u][i-1][j],f[u][i-1][j-k]+f[v][siz_v][k])` 
**”在前i个节点里选“包括u本身，即`f[u][1][1] = val[u]`**
- 这是一个依赖性的背包，如果要选儿子的话，就必须选根
	`k:0->j-1`，因为k如果等于了j，那么`f[u][i-1][0]+f[v][siz_v][k]`相当于从前i-1个点中选0个，一定不会选到根节点，不符合依赖的特性
- 在转移到u的时候，v一定已经转移完
	又有`f[u][i][j]`的转移只依赖`f[u][i-1][...]`所以可以利用滚动数组优化空间
- 实际实现的时候为了方便会加一个0号节点，所以在转移时j要转移到m+1
```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
#define endl '\n'
const int N = 301;

int n, m;
vector<int> g[N];
int dp[N][N];

void dfs(int u) {
    for(int v : g[u]) {
        dfs(v);
        for(int j = m + 1; j >= 1; j--)//因为压缩了空间，所以从后往前遍历
            for(int k = 0; k < j; k++)
                dp[u][j] = max(dp[u][j], dp[u][j-k] + dp[v][k]);
    }
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0); cout.tie(0);
    cin >> n >> m;
    for(int i = 1; i <= n; i++) {
        int t;
        cin >> t;
        g[t].push_back(i);
        cin >> dp[i][1];//初始化dp[i][1] = val[i]
    }
    dfs(0);
    cout << dp[0][m + 1];
}
```
