## P1240 诸侯安置

## P2422 良好的感觉
题目大意：给定一个正整数序列 $A$ ，求 $b = min_{i \leq k \leq j} \{A_{k}\}\times \sum_{i \leq k \leq j} A_{k}$ 的最大值
关键的一点是对于每一个 $A_{i}$ ，以它为最小值的连续的子段的b是随着子段的长度增大而单调递增的
所以可以找到**以每一个 $A_{i}$ 为最小值的最长区间，只计算这些区间的b的值，再取最大值**
要求以 $A_{i}$ 为最小值的区间，需要知道 $A_{i}$ 左边第一个大于 $A_{i}$ ，$A_{i}$ 右边第一个小于 $A_{i}$ 的数
如何在 $O(n)$ 的时间里求？可以想到用**单调栈**
这个题的关键就是发现区间答案的单调性从而舍去一些没用的区间，降低了时间复杂度

## AT_abc263_e 【ABC263E】 Sugoroku 3
一个非常经典的期望dp题，一共有 N 个格子编号 1 到 N。有一个人站在 1 号格子。
对于 $∀i∈[1,N−1]$ 号格子有一个 Ai​+1 面的骰子，写有 0 到 Ai​ 这些数。如果 ta 掷到了 k，他将往前走 k 格，走到 i+k 号方格。求走到 N 号方格的期望次数。对 998244353 取模。
定义 $f_{i}$ 为从i方格走到n方格的期望次数
$f_{i} = 1 + \frac{1}{a_{i} + 1} \sum_{k = i} ^ {i + a_{i}} f_{k}$
但是我们发现这个dp的转移是有环的，无法直接递推，需要用代数手段把它转化为无环的
$$
\begin{split}
f_{i} &= 1 + \frac{1}{a_{i} + 1} f_{i} + \frac{1}{a_{i} + 1}\sum_{k = i + 1} ^ {i + a_{i}} f_{k}\\
\frac{a_{i}}{a_{i} + 1} f_{i} &= 1 + \frac{1}{a_{i} + 1}\sum_{k = i + 1} ^ {i + a_{i}} f_{k}\\
f_{i} &= \frac{{a_{i} + 1}}{a_{i}} + \frac{1}{a_{i}} \sum _{k = i + 1} ^ {i + a_{i}} f_{k}
\end{split}
$$

## P3802 小魔女帕琪
有1-7七个数，第i个数有 $a_{i}$ 个，每次随机在所有数里选一个构成一个序列，求序列里连续的7个数都不同的长度为7的区间的期望个数
先考虑一个这个问题的简化版：**一个盒子，里面装有a个红球，b个黄球，你不断从里面拿出球，直到拿完，如果连续拿出的两个球颜色不同就得一分，问你的期望得分**
首先，根据期望的定义
$E(总得分) = \sum_{i}P(球i的颜色不等与球i+1的颜色)\times{1}$
i等于1时的概率很好算
$P(1) = 2\times \frac{a}{a+b}\times \frac{b}{a+b-1}$
在处理i等于2的时候，思考一个问题：P(1)，P(2)，……是相互独立的吗？
答案是，**是**
这里有几个思考角度
- 这几个球是完全随机被拿出的，它们在序列上的每一个点的出现概率是相同的，所以连续两个位置的球不同的概率与这两个位置在序列中出现的前后无关
- 连续两个位置的球是否不同与其他位置的球的颜色无关
所以，一个重要的结论就推出来了：所有$P(i)$都是相等的！
而答案就是
$E= \sum_{i}P(i) = 2\times \frac{a}{a+b}\times \frac{b}{a+b-1}\times(a+b-1) = 2\times \frac{ab}{a+b}$

---
回到这个问题，唯一的不同就是球的颜色从两种变成了7种，其他一模一样
$$
\begin{split}
n &= \sum a_{i}\\
E &= (n-6) \times p\\
&=(n-6) \times 7! \times \frac{a_{1}}{n} \times \frac{a_{2}}{n-1} \dots \frac{a_{7}}{n-6}\\
&= \frac{{7! \times a_{1} \times a_{2} \times \dots \times a_{7}}}{n(n-1)(n-2) \dots (n-5)}
\end{split}

$$

## P2657【SCOI2009】windy 数
不含前导零且相邻两个数字之差至少为 2 的正整数被称为 windy 数。windy 想知道，在 a 和 b 之间，包括 a 和 b ，总共有多少个 windy 数？
数位dp，转移好想， $f_{i,j}$  为位数为 i 的以 j 开头的windy数有几个，转移就是 $f_{i,j} = \sum_{|j - k| \geq 2}f_{i-1, k}$
但是统计答案是个问题，需要**逐位满足**，后面以统计所有**小于 a 的数**为例
- 先统计位数小于 a 的位数的，很简单
- 再统计最高位小于 a 的最高位的，也简单
- 最后统计其他的：先固定前 i 位与 a 的前 i 位相同，统计后面的最高位小于 a 的windy数的数量，代码辅助理解
```cpp
//n是a的位数，num[i]是a从后往前数的第i位的数
    for(int i = n - 1; i >= 1; i--) {
        for(int j = 0; j < num[i]; j++)
            if(abs(j - num[i + 1]) >= 2) ans += f[i][j];
        if(abs(num[i] - num[i + 1]) < 2) break;
    }
```
特别要注意这个 `if(abs(num[i] - num[i + 1]) < 2) break;` ，如果前 i 位固定下来后已经不是windy数了，那就必须break，否则会多算

## P3376 【模板】网络最大流
最大流模板
给定一个有向图，有两个特殊的点，源点和汇点，边有边权，表示这个边所能承受的最大流量，求从源点流向汇点的最大流量，和现实中的水流很像
如何求最大流？最朴素的做法是每次找到一条从源点到汇点的路径（增广路），路径上不存在权为 0 的边，这样，从源点流向汇点的流量就可以再增加**这条路径上的最小边权**
但这个贪心思想有一点问题，考虑这个图 （1 为源点，4 为汇点）
![[graph (1) 1.png]]
如果第一选了 $1 \to 2 \to 3 \to 4$ 这条路径，那么后面就无法再选任何路径了
如何解决？**反向边技术**
![[graph (1) 2.png]]
在刚才走过的路径中建立边权为流经这个路径的流量的反向边，路径上的边的边权相应的减少
这时再找增广路时，就可以再找 $1 \to 3 \to 2 \to 4$ 这个路径了
不断重复，最后无法找到增广路时一定就找到了最大流
这样看起来确实是对的，但为什么就是对的呢
可以这样理解，如果一个流经过了一个反向边，它实际上前进方向已经不是沿着反向边了，而是沿着这个反向边的起始节点，以建立这条反向边的那个流为后面的流动方向，而之前建立这条反向边的那个流其实也不经过这个边了，而是沿着这条增广路在算法执行的过程中实际走过的路径流，相当于这两条路径在这个反向边之后做了一个**交换**，他们的流量和无论是否交换都不变，所以这种交换是对的
这个过程，在算法导论或图论中通常被称为 **"Flow Cancellation"（流量抵消）** 或 **"Rerouting"（路径重路由）**
![[graph (1) 4.png]]
最后，对这个方法优化一下，用 bfs 分层，用 dfs 一次找到多条增广路，就是 dinic 算法了

## P1080【NOIP 2012 提高组】国王游戏
给定序列 a ，b 求一个排列 p ，$p_{1}$ 固定为 1 ，使得
$$
max_{1 \leq i \leq n} \frac{{\prod_{1 \leq j < i}a_{p_{j}}}}{b_{p_{i}}}
$$
最小
邻项交换排序
考虑所有人已经按任意的一种方式排好了队，把目光聚焦到队伍中一对相邻的人上
设这两个人中，排在前边的人的左手上的数字是 $a_{1}$ ，右手上的数字是 $b_{1}$
他的前面的人左手的数字的乘积是 $k$
排在后面的人的左手上的数字是 $a_{2}$ ，右手上的数字是 $b_{2}$
- 首先，这两个人无论是否交换位置，都对后面的人得到的奖赏没有影响
- 现在考虑是否交换以最小化这两个人得到的奖赏的最大值
	- 如果不交换
		这时这两人得到的奖赏的最大值 $x$ 就是 $max\left(  \frac{k}{b_{1}}, \frac{ka_{1}}{b_{2}} \right)$
	- 如果交换
		这时最大值 $y$ 就是 $max( \frac{k}{b_{2}}, \frac{ka_{2}}{b_{1}})$
	是否交换取决于是否 $x > y$ ，如果是，那么交换这两个人
	现在，每次遇到两个这样的人就交换他们，这其实就是一个**排序**
但现在的这个比较方法还是太过于冗长，不适合直接放在比较函数里，考虑如何化简
因为 $\frac{ka_{1}}{b_{2}} > \frac{k}{b_{2}}$ ，$\frac{ka_{2}}{b_{1}} > \frac{k}{b_{1}}$
所以要想 $x > y$ ，必须 $\frac{ka_{1}}{b_{2}} > \frac{ka_{2}}{b_{1}}$ ，即 $a_{1}b_{1} > a_{2}b_{2}$ 
放在比较函数里就是
```cpp
bool cmp(node x, node y) {
	return x.a * x.b < y.a * y.b;
}
```
按这个排序就行了

>[!info]- 为什么
>考虑什么时候会形成一个环
>设当前点坐标为 $(x, y)$ ，那么他能攻击的坐标就是 $(x \pm 1, y \pm 3)$ ，$(x \pm 3, y \pm 1)$ 
>如果在经过 k 次攻击后坐标又回到了 $(x, y)$ ，那么 k 一定是偶数，因为如果是奇数，那么只会走到 $(x + a, y + b)$ ，其中 a ，b ，都是奇数，因为奇数个奇数相加一定还是奇数
>所以这个图中没有奇数环，所以这是一个二分图

其实到这就可以跑二分图最大匹配了，本质求得是这个图得最大独立集，最大独立集 = 总点数 - 最大匹配数

这就需要在建图的同时规定好各个边的方向，不能后面再dfs染色
### 考验注意力（套路）的地方来了
 - **从奇数行的点连向偶数行的点**
 - **从 s 连向奇数行的点**
 - **从 偶数行的点连向 t**
 上面说的所有奇偶可以反过来，就是把整个图翻转了一下

## P3808 AC 自动机（简单版）
ac自动机，给定多个模式串和一个文本串，求文本串中匹配的模式串
先用trie树组织起所有的模式串，再把kmp算法的nxt指针（在ac自动机中叫fail指针）放到trie上
### 具体地说
一个节点的fail指针指向它父亲节点的fail指针指向的节点的与这个节点存的字符相同的子节点，如果没有，就再向上找，直到找到或走到根节点
那为什么要这么做呢？这本质上是在求从根节点到这个节点的所有节点构成的字符串的最长公共前后缀在字典树上对应的节点，知道了这个节点后，如果在匹配时失配了，就直接跳到fail指针所指的位置继续匹配，因为那个位置是改动最小的可能还能继续匹配的位置
还有，匹配时，当前的节点和当前节点的fail指针指向的节点，fail指针指向的节点的fail指针指向的节点的匹配次数都要更新，因为匹配到了这个字符串就说明一定匹配到了它的子串，而为什么它的子串在它前面不会被更新，而非得等到它更新的时候再被更新呢，因为，当前匹配的总是在字典树上最长的一段，当前指针始终代表着：**在所有以当前文本字符结尾的模式串前缀中，最长的那个**
这样，一个经典的ac自动机就建好了
### 但是，这太慢了 
时间复杂度的瓶颈在哪？在fail指针的不断递归地跳转上，一处是在建树的时候，要不断地跳到当前点的fail指针指向的节点，直到这个节点有一个孩子，与要找的字符一样，另一处是在匹配的时候，要更新这个节点所有的后缀，要不断地沿着fail指针跳转
### 优化
对于第一处，我们可以建立**虚拟节点**，这个节点在真正地trie树上是不应该存在的，但是在ac自动机中，这种设置可以避免大量的的fail指针的跳转，具体的，一个节点的虚拟节点中存的是这个节点的fail指针指向的节点的对应字符的子节点（如果没有，那这个节点就也是虚拟节点了），类似并查集里的路径压缩，这样做后，trie树就不再是那个树形的结构了，它变成了一个有向图，叫做trie图
对于第二处，我们可以把每个更新离线下来一起处理，观察fail指针的构成，会发现一个节点的fail指针只指向一个节点，并且不会形成环，那这是什么？这是一个**树**，叫fail树，对一个点更新，就是把fail树中的对应点更新，沿着fail指针向上更新，就是更新fail树上这个节点到根节点路径上的所有的点，是不是有点熟悉了，这就是一个简单的树上问题，可以一次dfs在 $O(n)$ 的复杂度下解决，这里，真的建出这个fail树太麻烦了，换一种方法，把它当作一个DAG，跑拓扑排序，就行了

### split
`void split(int p, int x, int &l, int &r)`
把以 p 为根的树按 x 的值分裂为两个数，右树的值都小于等于 x ，左树的值都大于等于 x ，函数返回左树和右树的根节点的编号
```cpp
void split(int p, int x, int &l, int &r) {
	if(p == 0) {//如果p指向空节点，l和r都设为空
		l = r = 0;
		return;
	}
	if(t[p].key <= x) {//如果根节点的值小于等于x，那么根节点和根节点左边的点都归为左树
		l = p;//左树的根为p
		split(t[p].rs, x, t[p].rs, r);//以p的右节点为根，继续分裂这个树，把分裂得到的左树设为当前左树的右子树
	} else {//反之亦然
		r = p;
		split(t[p].ls, x, l, t[p].ls);
	}
	pushup(p);
}
```
### mrg
`int mrg(int l, int r)`
把以 l 为根的树和以 r 位根的树合并，返回合并后的树的根节点编号
```cpp
int mrg(int l, int r) {
	if(l == 0 || r == 0) return l + r;//如果有一个树位空，那么返回不为空的
	if(t[l].pri > t[r].pri) {//按大根堆的形式合并，优先级大的在上面
		t[l].rs = mrg(t[l].rs, r);//合并l的右子树和r，合并后的树设为l的右子树
		pushup(l);
		return l;//返回l作为根
	} else {//反之亦然
		t[r].ls = mrg(l, t[r].ls);
		pushup(r);
		return r;
	}
}
```

## P7150【USACO20DEC】Stuck in a Rut S
平面上有一些点，它们不是朝向北就是朝向东，这些点现在同时以同样的速度开始沿着自己的朝向移动，如果碰到其他点的走过的轨迹，就停止，称产生这个轨迹的点阻碍了被挡住的点，这种阻碍的关系是传递的，如果 a 阻碍了 b ，b 阻碍了 c ，那么 a 阻碍了 c ，求每一个点阻碍的点的数量，保证每个点的横纵坐标不一样
因为每个点的横纵坐标不一样，所以向北的点只可能被向东的点阻碍，反之也一样，而这种阻碍的关系构成了一个有向无环图，在这个图上进行dp可以得到答案。
所以可以根据题意模拟，判断两个点是否有阻碍关系可以在 $O(1)$ 的时间内完成，枚举每一对向东的和向北的点，就可以在 $O(n^2)$ 的时间内建出这个 dag ，然后跑 dp 就行了
