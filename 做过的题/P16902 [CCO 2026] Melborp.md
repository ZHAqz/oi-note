给定序列 $b$ ，$b_i$ 表示 $a_{i}$ 是区间最小值的区间的数量，要求还原出序列 $a$

看到这种和区间最小值有关的题目，应该想到[[笛卡尔树]]
如果给定序列 $a$ ，求序列 $b$ ，是经典的问题，本质就是建一棵笛卡尔树
而这个题要反过来

首先容易想到 $O(n^2)$ 的分治做法
记 `calc(l, r)` 表示计算区间 $[l,r]$ ，然后每次递归中 $O(n)$ 求出所有合法的位置，再以这些位置为分界，向下递归
怎么看上去有点像递归加 RMQ 建笛卡尔树的样子

接下来考虑优化这个暴力
可以使用启发式的方法，只枚举到短的一侧，是比较经典的trick，可以无脑优化到 $O(n \log n)$，具体实现要复杂一些，见代码
```cpp
void solve(int l, int r, int ol, int orr, int oval) {
    if (l > r) return;
    auto check = [&](int p) -> bool {
        if (B[p] == 1LL * (p - ol + 1) * (orr - p + 1)) {
            A[p] = oval;
            solve(l, p - 1, ol, orr, oval);
            solve(p + 1, r, ol, orr, oval);
            return true;
        }
        if (B[p] == 1LL * (p - l + 1) * (r - p + 1)) {
            A[p] = oval + 1;
            solve(l, p - 1, l, r, oval + 1);
            solve(p + 1, r, l, r, oval + 1);
            return true;
        }
        return false;
    };

    for (int d = 0; l + d <= r - d; ++d) {
        if (check(l + d)) return;
        if (l + d != r - d && check(r - d)) return;
    }
}
// 入口调用：solve(1, N, 1, N, 1);
```

上面的做法都没什么意思，主要看如何优化到 $O(n)$
先说我自己的心路历程，首先发现 $a_{1}$ 的左端点一定是 1 ，从而可以知道右端点是 $b_{1}$ ，进而，可以知道 $a_{b_{1}}$ 的左端点也一定是 1 ，从而可以知道右端点是 $b_{b_{1}}$ ，这样递归下去，直到走到 n 或已经访问过的位置，不断从最右边没被访问的位置进行这样的计算，会发现这种管辖的关系形成了一个 DAG ，而在这个 DAG 上填数就容易了
其实，这个 DAG 是**一棵树**
更进一步，其实这个算法在做的事情，就是**在序列 $a$ 形成的笛卡尔树上不断剖分左链**
看上去有点像单调栈建笛卡尔树的样子？

其实，无论是分治还是找左链，本质都是通过 $b$ 序列还原出 $a$ 序列的笛卡尔树
另外，由于序列不一定是排列，所以是多叉笛卡尔树
