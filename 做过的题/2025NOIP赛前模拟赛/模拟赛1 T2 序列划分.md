给一个长度为 $n$ 的串 $S$，你想把它划分成若干段连续的子串，一共有 $2^{n-1}$ 种划分方法。
给一个整数 $D$，你希望划分方案中，如果我们把每个子串当作一个十进制下的数字（可以有前导 $0$），那么不存在两个相邻的子串不被 $D$ 整除。
输出方案总数，对 $10^9 + 7$ 取模的结果。
对于 $100 \%$ 的数据，满足 $\lvert S \rvert \le 5 \times 10^5$，$1 \le D \le 10^6$。

---

```cpp
f[i][1] = sum(f[j][0] + f[j][1])
```

# 逼近正解
这里主要的矛盾就是每次转移dp都需要从后往前扫一遍，有没有更快的方法？
如果做过[[ABC164D Multiple of 2019]]，会知道**使用桶来统计合法子串**的这个trick
然后对差分求子串是否合法的式子进行拆解
具体的，如果当前子串为 $S[j + 1, j + 2, \dots, i]$ ，那么就可以表示成 $pref[i] - pref[j] \times 10 ^ {i - j}$ 其中，$pref[i]$ 表示 $S[1, 2, \dots , i]$ 对应的数字
把整个式子放到模 d 的意义下，这个子串表示的数字是 d 的倍数，等价于
$$pref[i] \equiv pref[j] \times 10^{i - j} \pmod{d}$$
如果可以把式子两边同时除以 $10^i$ ，那么就可以分离变量 $i$ 和 $j$ ，得到
$$pref[i] \times 10^{-i} \equiv pref[j] \times 10 ^{-j} \pmod{ d}$$
预处理出等式一边对于每个 $i$ 的值，在dp的时候维护 $t[i]$ 表示 $pref[j] \times 10 ^{-j} = i$ 的位置的
dp值，就可以 $O(1)$ 转移了
具体看代码
```cpp
#include <bits/stdc++.h>

ll exgcd(ll a, ll b, ll &x, ll &y) {
	if(b == 0) {
		x = 1;
		y = 0;
		return a;
	}
	ll d = exgcd(b, a % b, y, x);
	y -= (a / b) * x;
	return d;
}

ll inv(ll a, ll b) {
	ll x, y;
	exgcd(a, b, x, y);
	x = (x % b + b) % b;
	return x;
}
```
